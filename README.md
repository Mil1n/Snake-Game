# 🐍 Neon Snake — Modern Arcade Edition

Стильная и динамичная версия классической Snake Game: неоновые цвета, glassmorphism-интерфейс, плавный аркадный геймплей, режимы, бонусы, препятствия, скины, тач-управление, достижения, миссии дня и локальная таблица лидеров.

## ✨ Особенности

- 🎮 Современный визуальный стиль: neon + grid + glass UI.
- 🕹️ Режимы игры: Arcade, Classic, Zen, Challenge и Time Attack.
- ⚡ Ускорение игры по мере роста счёта и комбо-множитель за быстрые серии еды.
- 🧠 Сохранение рекорда, топ-5 результатов, настроек, статистики и достижений в `localStorage`.
- ⏸️ Пауза/возобновление по кнопке и клавише `P`.
- ⌨️ Управление через `WASD` и стрелки.
- 📱 Тач-управление: свайпы по полю, экранные кнопки и haptic feedback на поддерживаемых устройствах.
- 🧱 Сложности, пресеты карт, режим Challenge и простой редактор своей карты.
- 🍬 Несколько типов еды: обычная, золотая, замедляющая, щит, яд, телепорт, x2, призрак, сжатие и заморозка препятствий.
- 🎨 Переключаемые темы оформления и скины змейки.
- 🏆 Достижения, карьерная статистика, миссия дня и экспорт результатов.
- 🔊 Аркадные звуковые эффекты с кнопкой выключения.

## 🚀 Быстрый старт

Открой `index.html` в браузере.

Или локально через простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

После этого перейди на: `http://localhost:8080`

## 🧪 Проверки

```bash
node -c game-core.js
node -c script.js
node test-core.js
```

## 🕹️ Управление

- `Space` — начать новую игру
- `P` — пауза / продолжить
- `WASD` или `↑ ↓ ← →` — движение
- Свайп по игровому полю — движение на телефоне
- Экранные кнопки `▲ ◀ ▼ ▶` — альтернативное мобильное управление
- В режиме карты `Своя карта` нажимай по клеткам до старта, чтобы добавить или убрать препятствия

## 🎯 Режимы игры

- **Arcade** — основной режим с бонусами, препятствиями и ускорением.
- **Classic** — классическая змейка без особых бонусов.
- **Zen** — стены переносят змейку на другую сторону поля.
- **Challenge** — старт с готовой картой препятствий.
- **Time Attack** — ограничение по времени: набери максимум очков до таймера.

## 🎯 Режимы сложности

- **Easy** — спокойная скорость без процедурных препятствий.
- **Normal** — сбалансированный режим с постепенным появлением препятствий.
- **Hard** — быстрый старт и больше препятствий.
- **Insane** — максимальная скорость, частые препятствия и без стартового щита.

## 🍬 Бонусы

- Розовый импульс — `+10` очков.
- Золотой импульс — `+30` очков, исчезает через несколько секунд.
- Голубой импульс — слегка замедляет игру.
- Зелёный импульс — даёт щит от одного столкновения.
- Красный импульс — яд: штрафует очки, длину змейки и комбо.
- Фиолетовый импульс — телепортирует голову в безопасную клетку.
- Жёлтый импульс — удваивает следующий результат.
- Белый импульс — временно разрешает проходить сквозь хвост.
- Бирюзовый импульс — аккуратно укорачивает змейку.
- Синий импульс — временно замораживает появление новых препятствий.

## 📁 Структура проекта

- `index.html` — разметка игры, HUD, настройки, мобильное управление, статистика, достижения и лидерборд
- `styles.css` — оформление интерфейса, темы, адаптивность, анимации и состояния
- `game-core.js` — чистые конфиги и функции игровой логики для браузера и Node-проверок
- `script.js` — игровая логика, режимы, бонусы, препятствия, рекорды, звук и touch-события
- `test-core.js` — быстрые проверки чистой логики
