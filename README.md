# 🐍 Neon Snake — Modern Arcade Edition

Стильная и динамичная версия классической Snake Game: неоновые цвета, glassmorphism-интерфейс, плавный геймплей, бонусы, препятствия, скины, тач-управление и локальная таблица лидеров.

## ✨ Особенности

- 🎮 Современный визуальный стиль: neon + grid + glass UI.
- ⚡ Ускорение игры по мере роста счёта.
- 🧠 Сохранение рекорда и топ-5 результатов в `localStorage`.
- ⏸️ Пауза/возобновление по кнопке и клавише `P`.
- ⌨️ Управление через `WASD` и стрелки.
- 📱 Тач-управление: свайпы по полю и экранные кнопки.
- 🧱 Режимы сложности с препятствиями и ростом уровня.
- 🍬 Несколько типов еды: обычная, золотая, замедляющая, щит и яд.
- 🎨 Переключаемые темы оформления: Cyber Mint, Purple Neon, Lava, Matrix и Retro CRT.
- 🔊 Аркадные звуковые эффекты с кнопкой выключения.

## 🚀 Быстрый старт

Открой `index.html` в браузере.

Или локально через простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

После этого перейди на: `http://localhost:8080`

## 🕹️ Управление

- `Space` — начать новую игру
- `P` — пауза / продолжить
- `WASD` или `↑ ↓ ← →` — движение
- Свайп по игровому полю — движение на телефоне
- Экранные кнопки `▲ ◀ ▼ ▶` — альтернативное мобильное управление

## 🎯 Режимы сложности

- **Easy** — спокойная скорость без препятствий.
- **Normal** — сбалансированный режим с постепенным появлением препятствий.
- **Hard** — быстрый старт и больше препятствий.
- **Insane** — максимальная скорость, частые препятствия и без стартового щита.

## 🍬 Бонусы

- Розовый импульс — `+10` очков.
- Золотой импульс — `+30` очков, исчезает через несколько секунд.
- Голубой импульс — слегка замедляет игру.
- Зелёный импульс — даёт щит от одного столкновения.
- Красный импульс — яд: штрафует очки и длину змейки.

## 📁 Структура проекта

- `index.html` — разметка игры, HUD, настройки, мобильное управление и лидерборд
- `styles.css` — оформление интерфейса, темы, адаптивность и анимации
- `script.js` — игровая логика, режимы, бонусы, препятствия, рекорды, звук и touch-события
